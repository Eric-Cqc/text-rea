# 文字版 REA：从这里开始

文字版 REA（`text-rea`）把软件 REA 里「证据 → 机制 → 可迁移判断」迁到**文字写作**：拆参考写法、借新材料成稿、按反馈改稿、做读者审读。

参考提供问题、组织或表达方法；本次材料支持事实；现稿是编辑基线。需要新稿时交付完整正文；需要拆解时指出原文位置、具体写法和适用条件。参考中的事实不能随写法进入新稿。

## 安装与触发

```bash
cp -R skill ~/.codex/skills/text-rea
```

自然语言说「用文字版 REA / text-rea」，附上参考、素材或现稿即可。详见根目录 [README.md](../README.md)。

可安装入口：[skill/SKILL.md](../skill/SKILL.md)（version **1.2.0**）。
