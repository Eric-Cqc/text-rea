# Acceptance of a first run · text-rea

Used by Quickstart / `docs/QA.md`. No user-recruitment language.

## Pass

After install + reload, with either a **golden example** under `skills/text-rea/examples/` or the operator’s own short reference + materials, one explicit `text-rea` trigger yields at least one of:

1. **Close-read:** reusable writing moves with locations in the reference; or  
2. **Transfer / draft:** prose (or revise notes) where reference-owned method and material-owned facts stay separable; or  
3. **Thin-input deferral:** numbered clarifying questions / unknowns — **without** fabricated facts.

## Fail

- No trigger after a green `scripts/verify-install.sh`.  
- Long polished prose with no sources when materials were missing.  
- Instructions require the author’s private machine paths.  
- README/docs frame the product as job-interview prep.
