# 文字版 REA：简明用法与阅读路线

适用于本仓库可安装的正式版 `text-rea`（见 [`skill/SKILL.md`](../skill/SKILL.md)）。可以直接说「用文字版 REA / text-rea」，说明用途并给出手头材料；下面的分类供助手选择做法，无需用户填写表格。

入口总览：[00_从这里开始.md](00_从这里开始.md)。

## 先按这次要完成的事使用

| 这次要做什么 | 有哪些材料就先给哪些 | 应交付什么 |
|---|---|---|
| 拆一篇文章的写法 | 参考全文或节选，想弄清的地方 | 带原文位置的作用解释、可迁移动作及适用条件 |
| 借参考写一份新稿 | 参考、新材料、读者和用途；已有要求继续有效 | 使用新材料的完整正文，保住必要事实与关系 |
| 从多篇文章或聊天提炼写法 | 原文、版本及已知作者；认可范围能辨认就保留 | 有来源、按情境分组的局部画像；区分用户原话和认可的助手稿 |
| 按反馈改现稿 | 当前稿、反馈、已认可部分与仍有效的要求 | 修订正文；必要时简述实质变化与未解决项 |
| 研究后写长文 | 研究问题、用途、已有资料和参考 | 有依据的完整文章；关键资料缺口保持可见 |
| 比较方法或判断效果 | 共同材料、候选、评价目的与已知运行条件 | 真实条件下的比较记录，分别报告事实、任务完成和读者判断 |
| 改进这个Skill | 具体失败、实际输入、输出与执行记录 | 有范围的修改候选、依据与待验证部分 |
| 将一种用途固化为专用Skill | 已核参考、实际任务及条件边界 | 聚焦的入口、条件化规则和必要示例 |

普通知识问答、改一个错别字或已明确的局部改词，按当前任务直接处理。用户明确点名本Skill时，也保留所要求的局部范围。

## 一次普通使用怎样走

先分清参考、事实、现稿和反馈。参考提供写法，新材料支持新稿事实；已有稿件和反馈则决定本轮修哪里。材料身份不明时保留未知，能由已给信息确定的事由助手承担判断。

接着从参考找少量有位置的具体动作，判断它们能否服务新读者。可以借解释顺序、对象接续或叙事安排；每一项都要落到本次材料。

需要新稿时直接交付正文。需要修改时从已采纳版本继续。写完核事实、关系、持续约束和目标作用，再处理节奏与自然度；未发现需要修改的地方，可以保留现稿。

普通使用不用默认打开全部研究记录、建立完整案例JSON、生成多路候选或启动多位助手。比较和实验按本次要求及已有授权安排。

## 给执行助手的阅读路线

正式版项目入口是[SKILL.md](../skill/SKILL.md)。先读入口，再按问题取用以下文件；各条路线仍承担当前任务所需的事实与约束检查。

| 当前需要 | 主要参考 | 何时补读 |
|---|---|---|
| 普通写作、口述整理 | [普通写作](../skill/references/writing.md) | 本人文风要求补读[风格检索](../skill/references/style-retrieval.md) |
| 单篇拆解 | 入口已给任务层、篇章层与段落动作要求 | 复杂过程用[完整协议](../skill/references/protocol.md) |
| 借参考写新稿、多参考融合 | [迁移指南](../skill/references/transfer.md) | 不知道如何落成段落时查[写作动作](../skill/references/writing-actions.md) |
| 多篇画像、口述、人机混合稿 | [语料与画像](../skill/references/corpus-profile.md) | 转写新题时再查迁移指南 |
| 多处反馈修订 | [反馈落实步骤](../skill/references/protocol.md#将反馈落实为修改) | 人物、事件、条件或先后有歧义时查[关系检查](../skill/references/relation-checks.md) |
| 多来源长文研究 | [长文研究](../skill/references/research.md) | 参考结构要迁入新题时查迁移指南 |
| 读者评价、多候选与方法比较 | [Harness](../skill/references/harness.md) | 改可复用方法或选版本时查[迭代协议](../skill/references/iteration.md) |
| 追查某条规则从哪来 | [证据说明](../skill/references/evidence-notes.md) | 需要核研究依据或适用边界时阅读；它本身不是新稿事实材料 |

这些是按现有文件整理的阅读建议，尚未测量其是否减少读取量、耗时或改善成稿。资料很多时，先取本题需要的部分；关键条件和来源位置要保留。
