# Quickstart — 最小输入包

Paste these four fields when you trigger **text-rea** (`用文字版 REA` / `$text-rea`). Empty fields are gaps — the skill should ask or degrade, not invent facts.

---

## 1. 材料（facts for *this* run）

What is true for this piece? Paste notes, quotes, data, or links you authorize.  
**Do not** ask the skill to invent experience you did not provide.

```text
材料：
（粘贴）
```

## 2. 参考（method source）

Which text should lend *structure / moves* — not sentences to copy?

```text
参考：
（粘贴路径、链接或摘录；可指向仓内 examples 之一）
```

## 3. 读者

Who reads this, and what must they understand or be able to do after?

```text
读者：
（一句话）
```

## 4. 成功标准

What does “done” look like for this run?

```text
成功标准：
（例如：800 字说明文；保留材料分界；给出 3 个可定位的写作动作）
```

---

## Acceptance of a first run

Canonical checklist: [`first-run-acceptance.md`](first-run-acceptance.md).

A successful first run produces **at least one** of:

1. **Located moves** — writing actions tied to places in the reference; or  
2. **Short draft** — prose usable by the named reader, with materials owning facts and reference owning method.

It must **not**:

- Fabricate facts missing from 材料  
- Copy reference sentences as if they were yours  
- Expand into job-seeking / interview prep unless that was the explicit writing task *and* materials support it (this product’s default non-goal remains: no job-prep as the main product)

## Minimal demo (repo samples)

| Field | Demo fill |
|---|---|
| 材料 | Public facts from `examples/P010_唐三彩载乐骆驼俑.md` sources listed at bottom of that file |
| 参考 | Same file as method demo of museum-label structure |
| 读者 | Museum visitor, 2 minutes |
| 成功标准 | ≤400 字说明；物件—空间—人物层次清楚；事实可回链到所给资料 |

Trigger example:

```text
用 text-rea。材料与参考用仓内 P010；读者＝博物馆观众；成功标准＝短说明文且材料/参考分界清楚。
```
