# 本仓结构说明

```
text-rea/
  README.md          # 是什么 / 怎么装 / 怎么用 / 边界
  LICENSE            # MIT
  CHANGELOG.md
  skill/             # 可直接安装的完整 Skill（权威入口）
    SKILL.md
    agents/
    references/      # writing / transfer / protocol / harness …
  docs/              # 给人读的入口与用法（链到本仓相对路径）
  research/          # 研究摘要、历轮索引、缺口与案例总账
  pilots/
    samples/         # 公开安全短样例正文
    records/         # 对应使用记录（方法说明）
```

## 怎么读

1. **只想用**：读 [README.md](../README.md) → 安装 `skill/` → 说「用文字版 REA」。
2. **想弄清一次任务怎么走**：读 [简明用法.md](简明用法.md)，再按需打开 `skill/references/`。
3. **想看成果长什么样**：打开 [pilots/README.md](../pilots/README.md) 里的完整用稿与使用记录。
4. **想追方法从哪来**：读 [research/README.md](../research/README.md)；历轮正文大多未收录，索引里保留文件名。

## skill vs docs vs research vs pilots

| 目录 | 角色 |
|---|---|
| `skill/` | 给 Agent 执行的正式规则；可独立拷贝安装 |
| `docs/` | 给人的入口、用法与结构说明 |
| `research/` | 研究向摘要与证据范围；非现行操作手册 |
| `pilots/` | 脱敏短样例 + 方法使用记录 |

执行时以 `skill/SKILL.md` 为准；`docs/` 与 `research/` 不覆盖 Skill 规则。
