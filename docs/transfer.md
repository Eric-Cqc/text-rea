# 从范文机制到新稿

用于“提炼这篇的写法，换一批材料写”“融合几份参考的长处”。普通写稿无需建立完整画像。以下是提示与编辑流程；没有训练作者向量、解耦网络或蒸馏模型参数。

## 确定这次允许变化的内容

复用[成稿主线](writing.md)中已确定的用途、事实、编辑范围和虚构权限。补清参考这次贡献什么，以及新材料缺什么，即可开始迁移；无需再建立第二份合同。

“保留内容”由任务决定。把抱怨写得礼貌，通常仍要保住抱怨的对象与诉求；用户明确要改立场，则须记录获准改变的主张，不能把这次变化误判为内容错误。

## 将源动作改造成目标动作

先观察，再抽象，最后填入新事实，避免把范文当实体替换模板。

`源文具体位置与动作 → 可能解决的读者问题 → 新任务是否存在这个问题 → 用新材料怎样解决 → 何时不适用`

例如，某篇用户局部认可的产业报告把产品放入交付链，解释每个环节对最终使用结果的影响。可迁移的候选机制是“沿主体、动作与结果解释条件如何相接”。它不要求新文本也有两条产业主线、公司名或表格。换成月食科普，可用地球挡光、地影区域与经过大气的阳光解释现象；无需把它写成产业链。迁移若仍离不开原文的主题名词，应再检查提炼出的究竟是作用还是内容。

这来自一份参考的回顾性观察，不足以证明作者稳定习惯；要形成作者画像，另找不同题材和反例。用户只认可某节时，机制证据止于该节。

若参考里的具体关系适合改造成问题，先问新题是否也需要回答它，再从新材料取答案。核对答案的实体类型、关系、具体程度和事件阶段：地点类别不能随意换成城市，正在试验不能写成已经验证。新题没有对应关系时换结构；关系可能成立但材料不足时记未知或补查，不能把“未找到”写成“不存在”。参考中的第一人称和人物经历也不授予新稿相同的叙述身份。

若用户希望迁移的不只是表达，而是观察或判断方式，先按[思维与表达提炼](thinking-patterns.md)把机制写成条件化动作；沿动作确定本题缺什么证据，再回到本节成稿。

## 用合同重建全文

先安排每段完成的读者任务和必要事实，再选择句式、节奏及语气。采用多个参考时，给每个参考分配具体用途；如一个提供论证顺序，一个提供解释节奏。若它们冲突，按新任务和用户指定优先项取舍，不使用没有可解释含义的“各占 50%”。

需要具体写法时，读[写作动作与完整示例](writing-actions.md)：它按读者的断点组织候选动作，并给出事实解释、虚构选型和虚构叙事的成文。动作仍需本次参考锚点和新任务材料；库中示例不当作本稿事实或经过验证的效果。资料足够时，把选定动作落实成正文即可。

需要核迁移落点或帮助学习写法时，选本轮关键动作对齐 `源文锚点及其作用／新稿锚点及实际实现／仍未实现或有损失之处`。能找到某个词，不等于它支持所贴的策略标签；说明该片段怎样参与动作、信息顺序或上下文关系。新稿用了相近词，也不等于实现了同样作用。找不到依据时，保留作用假设或迁移未落实的判断，不补造原作者意图、人物心理或读者效果。普通写稿无需逐句制作对照表。相关设计及范围见[范例策略与迁移落点](evidence-notes.md#范例策略与迁移落点)。

### 多参考怎样真正合到一起

复杂融合先记一张简短的组合表：`目标段落或作用／参考位置／采用的动作／与其他动作的冲突／取舍及理由／在成稿怎样核对`。这张表服务写作，无需作为正文交给读者。兼容的动作也不全量叠加：短句、密集比喻和多次转折分别成立，放在一起仍可能使一段拥挤。先围绕该段职责组合，再看相邻段落的节奏与承接。

用户给出百分比时，把它保留为偏好输入，落实成可观察的选择，例如“解释主线沿 A，细节处少量采用 B 的比喻”；没有分母、计量单位和实际核算，不报告“已实现 70%”。离散选择如叙述人称、是否回溯、是否引用原话，需要明确采用哪种方式及范围，不能用取平均值解决。若两种结构都合理但无法同时成立，可用两个短样段帮助确定方向。

把**改写范围**与**虚构权限**分别设定。大幅调整结构和语言仍可要求全部事实保留；新增回忆、动作、心理、时间或因果则需材料支持，或任务本就允许虚构。“深度改写”不自行扩大后者。未实际统计的句长、修辞密度不填精确值；只按措辞或标点印象也不能判定来源由人或 AI 创作。

后续调整只更新被指向的规则，并保留版本、适用任务和仍有效的限制。成稿的其他属性可能随之变化：减少比喻可能同时缩短句子，改视角可能丢掉信息。回读实际差异与必要内容，不能因未调某个选项就声称该维度未变。换文类或任务时，重新核对先前的视角、结构和虚构权限是否适用，避免无声继承。

这些操作借鉴 [Quill 的分维度融合](https://github.com/sevenwoood/quill-skill/blob/23b58b48e72675b0b2ad035b7d098653d8f503fd/SKILL.md)和局部更新思路，并根据其静态示例的局限重新设计；不是对该项目效果的复现。来源取舍见[证据说明](evidence-notes.md)。

成稿后回到新材料核人物与关系，尤其检查容易被目标文风带走的内容：独有名词被换成参考中的人物，拒绝变成同意，可能变成必然，关联变成因果，今天回望变成当时心理。再读全文，看目标作用是否出现，开头或结尾是否集中堆积同类手法。只修发现的失败，不为增加风格感自动添加情节。

长文分段时，分别保留近期**参考上下文**和已写的**新稿状态**：前者只帮助理解源文指代和作用，后者记已覆盖内容、尚未兑现的承诺与事实来源。不要让参考的事实混进新稿状态，也不要让摘要替代关键原文。需要检索时，把计划写成待回答问题；计划中临时拟出的数值、主体或因果不作为证据。材料不足时不靠猜答或自报置信度补齐；保留有依据的否定、限制和负面结论。

若出错，先看实际证据：所需事实不在已检材料、材料有但未取到、取到后被改写变形，或多来源版本冲突。没有检索与输入记录时，成因保持未定。不要为了修一个词而重跑整篇，也不要把继续搜索当成能修复所有问题。

## 需要多个候选时，先查能否用，再决定更像谁

只有任务确实需要选稿且资源允许时才多生成，预先定候选数量或停止条件；普通写稿不强制开多路。保留首稿、被弃候选、筛除原因和最终选择。先用新材料检查必须保留的主张、关系与硬约束，再在符合条件的稿中比较目标作用和自然度；都不合格就报告未达，不因必须选一个而降低要求。

如果使用相似度、作者识别或模型评分，核对**实际输入两端**。内容保留应比较候选与本次事实材料或保留清单，写法匹配才比较候选与参考。还要区分用于生成或选稿的信号与用于最终评价的证据；重复使用同一个分数只能说明对它的优化结果。数值无效、评分失败或缺上下文时保留状态，不转换成满分。具体记录见[Harness](harness.md)。

风格强度以实际稿件的变化校准：目标写法是否出现、必需内容有无损失、其他属性怎样联动。不要把嵌入插值系数、LoRA 权重或作者分类分数翻译成“文章有多少百分比像某人”。远离原文不是所有任务的目标；原文已经合适时可保留，不照搬训练数据里“删除未变化候选”的规则。

这些是从 [TinyStyler](https://arxiv.org/html/2406.15586v2) 的候选筛选、自蒸馏和 [StyleRemix](https://arxiv.org/html/2408.15666v1) 的分轴控制中提炼的候选做法。这里没有加载作者嵌入、训练适配器或验证自动分数；静态实现的输入与回退问题见[证据说明](evidence-notes.md)。

## 校准时同时保留两种困难样本

- **改得多但守住内容**：允许大幅换句式和顺序，确认关键主张与关系仍在。不要因字面变化大就判内容丢失。
- **改得少却伤害内容**：只改一个否定、主体或条件即可改变意思。不要因词语重合高就判忠实。

人工构造的检查例：新材料说“满月时，月亮也不一定穿过地影”；改成“每逢满月，月亮都会穿过地影”，只换少数字词，却破坏了量化与条件。此例用于说明判法，不是用户原话、真实系统失败率或独立测试结果。校准集还需有不该修改的正例，防止一律判错。

方法线索：[StoryTrans](https://aclanthology.org/2023.acl-long.827/)区分篇章风格操作与内容恢复，但其模型仍有内容保留限制；[Mind the Style Gap](https://aclanthology.org/2025.findings-emnlp.1175/)用有意构造的内容错误检验评价器。这里借用分工和困难样本设计，不移植论文模型或效果数值。

另见 [Text Fact Transfer](https://aclanthology.org/2023.emnlp-main.288/)、[IRP](https://aclanthology.org/2023.emnlp-main.729/)和 [RePA](https://aclanthology.org/2025.acl-long.1250/) 的问题转移、细粒度取证与分段状态方法；其前提和原始提示的取舍见[证据说明](evidence-notes.md)。
