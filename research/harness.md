# Text REA V2 Harness：可复查的案例与评价记录

本文件用于保存可复查的案例与比较结果。按当前问题选字段，不要求每次填完整表。既有回顾诊断、开发例、未隔离三稿探索、用户盲读与公开标注校准的范围见[证据说明](evidence-notes.md)。这些记录尚未证明 V2 的方法优势。不同文类和不同评价目标分别呈现，不压成单一总分。

## 评价实际候选与实际选择路径

比较流程候选时，核评分是否使用该候选实际产生的正文或中间结果。重放旧输出只能支持对应旧流程；若只有候选成本改变，旧质量分也不能证明新流程保持质量，换成最低分门槛仍不能解决这个缺口。缓存可复用的范围与所指输入、输出及方法版本一并核对；没有新结果时记未测，不为填分默认重跑。相关来源与本地改造见[候选响应与分支选择](evidence-notes.md#候选响应与分支选择)。

多种方法按任务选择时，记录决定发生在执行前、看候选后还是看最终评价后，以及选择者实际可见的信息。比较实际选用路径的结果和成本；各分支成功题目的并集可作事后覆盖参考，不能充作选择流程已取得的成功率。选择规则、分支及所用样例的开发与最终检验范围同样保留；普通写作沿用途选方法，无需额外建立自动路由器。

## 原始回答、模型建议与汇总分开

需要汇集多次反馈或导入标注时，保留回答对应的任务、候选及问题版本、实际回答者或产生方式、原始内容和来源位置。字段叫`Response`、`annotation`或带有用户ID，不足以证明是人独立读后作答；模型建议可能被复制成标注，旧标签也可能由程序导入。能核到时记录建议是否可见、是否被采纳或修改；不知道就留未知，不凭结果与建议相同反推读者照抄。编辑自查、模型判断、已有数据标签与本项目真实读者回答仍分开计数。

把批评改写成评价标准时，保留原话、所评稿件及派生关系；区分原评价的好坏判断、条件和强度，与新稿希望达到的状态。只有“回答应该怎样”的标准，不能推出旧稿已经通过或失败。原话或上下文缺失时标明来源范围，派生标准按`criteria_audit`核本题适用性；满足标准的证据另看实际稿件。相关来源见[批评与派生标准](evidence-notes.md#批评与派生标准)。

原始回答保留，订正、裁决或汇总另记所依据的记录和规则，不能用最新总分覆盖不同人的原选择。投票只汇集同一版本、同一问题上真实重叠的回答；跨题出现三位评审，不等于每题三票。事实分歧回到来源核对，偏好分歧可以并存；取得共识、标成`ground_truth`或多数选择都不能单独证明事实正确。

引用外部导出时，核它是否包含原回答、所见问题、候选及建议内容；只有ID或最近更新时间，未必能恢复当时阅读状态。普通一次反馈可以只保留原话、所看版本与适用范围，无需建立完整标注平台。若只拿到汇总或来源不明的标签，说明缺口，不把它充作新增人工证据。

## 各项怎么判

| 检查 | 记录方式 | 通过条件 |
|---|---|---|
| 来源身份 | 原文位置、版本和可读范围 | 每个机制能回到对应文本；节选不冒充全篇 |
| 认可范围 | 用户原话、对象、版本与具体位置 | 局部认可不扩展到其他章节、后来版本或事实正确性 |
| 语料身份与画像 | 标作者、转录或编辑来源、证据角色；按文类与题材分组，保留反例 | 用户认可的助手稿不冒充本人写作，记忆摘要不当语言样本；从已有反馈产生的规则不在同一例上声称泛化 |
| 口述整理 | 标原片段、问题类型、处理依据与改后位置；语体目标单列 | 原问题得到处理，否定、情绪与不确定性未被洗掉；补词和新关系有依据，转录疑点不靠猜名补齐；参考新增内容也须核 |
| 参考污染 | 标记新稿里来自参考的事实、独特句式和情节 | 未经授权的内容不进入新稿；抽象功能可迁移 |
| 迁移适用与故障位置 | 核参考问题在新题是否适用，核答案的关系、类型、具体程度与阶段；有实际中间记录再判断错误环节 | 缺证据与不适用分开，检索问题与改写错误分开；无过程证据时不编故障原因 |
| 事实忠实 | 将新稿拆为原子主张，连到事实账；从必保留内容造问答 | 关键事实无错漏、无凭空新增；未查证项降级或留空 |
| 关系忠实 | 核对同一事件、身份、因果和时间边；整段阅读其隐含关系 | 句子相邻不暗示未经确认的关联；未知关系保持未知 |
| 读者绑定与时间语义 | 先按现稿记录可辨认实体和关系，再核来源；比较实际发生先后 | 不用内部知识替现稿解歧义，不把倒叙当次序错误，不把先后当因果；资料未定序时不强迫全排序 |
| 核验状态 | 保存成功范围、原始中间结果及错误原因 | 尚未检查、失败、证据不足与反驳分开；空结果、回退原值或格式通过不计为语义通过 |
| 主观归属与跨图顺序 | 逐句核当时心理、拍摄动机、人物性格与身体感受的说话人和依据；多张照片核日期及关系 | 今天回望可以标成联想，当时状态须有材料；主题排列不写成未经确认的同日连续过程 |
| 作用完成 | 针对读者任务提出可回答问题或实际操作检查 | 读者能找到结论、理解关系或完成步骤；具体条件随任务定 |
| 长文研究与分节输入 | 必要问题对应实际证据和章节职责，保留实际进入写作的材料 | 视角数量不当覆盖结果，主题相关不当已答问题；接口字段存在不当实际传入，引用格式不当证据支持 |
| 风格迁移 | 只对用户指定的维度观察，分开头/中段/结尾 | 目标作用出现，且没有过度风格化或语义损失 |
| 多参考组合与调整 | 按目标作用记来源动作、冲突、取舍；调整后读实际差异 | 百分比偏好不冒充已测配比；改写范围与虚构权限分开；未调整的规则不代表输出维度必然不变，换任务核状态适用性 |
| 修订有效 | 记录反馈意图、修改位置、前后差异 | 原问题解决，已认可内容和事实未被破坏 |
| 是否需要修订 | 先标问题位置及来源，再列原文保留与修改的可能收益和损失 | 用户点名与编辑假设分开；五档区分必要性与偏好，允许两种都行或原文更好；没有修订史不等于无问题，出现后稿也不等于原稿必错 |
| 位置与改法分开 | 多名编辑分别记录选中的位置；只对共同选中的位置比较改法和理由 | 位置分歧保留为分歧；修改类型一致不等于具体改写相同，任何单份后稿都不是唯一金标准 |
| 反馈到修改 | 每条反馈对齐一个或多个实质改动；额外改动标主动修改；修订说明再回对差异 | 点名问题确实回应，未回应和越界修改可见；说明不误报完成或漏掉重要改动 |
| 人工修改成本 | 有实际计时时记录把候选改到可用所需秒数、轮次和遗留问题 | 成本与最终质量并看；无计时标未测，不用字数或编辑感觉补数 |
| 版本对齐 | 先对齐段落作用、句子主张与必要片段，再标改动及其目标 | 机械字词差异不直接等于改动意图；点名句消失后，还检查同一问题是否换了形式出现 |
| 持续约束 | 汇合初始任务和每轮仍有效的要求，逐项回读 | 新反馈被解决，同时旧约束没有悄悄失效；冲突和未达项明示 |
| 主观偏好 | 同一事实包的候选匿名成对、交换顺序、记整体及专项理由 | 用人类评价说明偏好和分歧；整体选择与简练、忠实等专项选择可不同，不把模型票当最终事实 |
| 遵令、可接受、偏好 | 分开记录是否执行指令、是否能用于目标场景、在可接受稿中更想用哪份 | 允许两稿都可或都不可；首选不等于整体认可，遵令不等于事实正确 |
| 可接受性待核 | 若缺段落职责、领域事实或原始约束，逐候选记待核与缺什么 | 不把“更短、更顺”直接升格为可接受；没有证据时也不把轻微措辞差异直接判错 |
| 数据来源与伪重复 | 标任务家族、原文 ID、候选稿 ID、评审人或评审模型及版本；核数据卡和实际字段 | 同题多模型 split、多名评审或同文多配对按共同任务分组；`chosen/rejected` 字段名不足以证明人工标注 |
| 句子自然度 | 在具体案例里标出读者不喜欢的句子及其作用；对照删改后能否仍讲清关系 | 抽象总结若不增加信息且打断解释，可删或换成具体过程；单例反馈不变成全局禁句 |
| 解释增量 | 为补充句记录前文锚点、潜在读者问题、衔接、信息增量与新事实来源 | 先连得上且不误导，再看是否帮助目标读者；“明示原意”与“添新事实”分开，必要转场允许保留 |
| 理解与顺畅 | 分开收集读起来是否省力、自觉理解和实际问答或复述 | 三项不能相互代替；提问覆盖不足时标未测，审美偏好不冒充理解正确 |
| 题目质量与可答性 | 题目先按来源事实制定，标关键支持位置、误解型选项、唯一答案和不看文章能否猜中；逐候选记可答性，再收读者答案 | 允许“本文无法回答”；稿中找得到对应句不等于读者答对，读者答对几题也不等于理解全文；同题再读标已有暴露 |

## 采用外部或自动生成的评价标准时

按 `criteria_audit` 将具体判法连回本题要求、来源事实或明确标出的研究预设，分清硬约束、质量观察与偏好。文类必要条件需要说明作用依据；模型或编辑提出的标准先核适用性，不自动成为用户要求。缺依据或范围不符时修改、不采用或记待核；不为凑固定维度数增加标准。

同题比较使用相同的已定标准，记录标准在见稿前还是见稿后产生。写后发现的新问题可以检查，但须单列，不能把为某份候选新增的标准伪装成预先条件。普通改稿不需要额外造评分表。相关机制来自[WritingBench](https://arxiv.org/html/2503.05244v4)的按题生成与人工复核，未移植其评分模型或成绩。

数据标签也要追到产生方式：社群点赞衍生的成对标签、读者同时看到候选后的直接选择、模型判分分别记录。[LitBench](https://arxiv.org/html/2507.00769v1)的主要标签与另行开展的人工阅读研究属于不同证据；不能因字段叫 `chosen` 就放入直接读者评阅结果。

引用基准成绩时，先核评价单位和聚合层级：句子、段落、全文、同题配对还是各模型的平均分，样本与来源家族怎样分组。系统均值与人工均值相关，不直接证明每篇文章的评分或同题选稿可靠；缺相应层级结果时保持未知。[HoWToBench](https://aclanthology.org/2026.acl-long.317/)的相关研究说明了区分层级的必要。语病最小纠错、全文自然度和作者识别也有不同目标，不能只因都是中文就互换成绩。

需要汇成总分时，保存本题维度、父子关系、权重的来源与符号、尺度、缺项及失败的处理，并核实际实现。显式权重可能包含固定插入项或回退，名称叫“整体质量”不说明它覆盖了哪些判断。硬约束仍单独检查；缺失不擅自补成中间分，未知也不经平均变成通过。没有选稿需要时，直接记录具体问题，不强制造总分。

若指标选择、权重或评分模型利用了人工标签，记录实际用于拟合或校准的数据及标签、规则冻结时间，以及与最终被评任务是否重叠。利用目标数据标签挑选或调权的结果可说明这些数据上的组合表现；未有独立检验时，不称为未见任务上的评价能力。先看过标签再冻结规则，也不会使同一批数据变成未见数据。这里参考[B06的目标数据组合指标](evidence-notes.md#组合指标的校准范围)；普通不评分的改稿无需增加校准步骤。

## 候选选版与分数输入

有自动指标或多候选选择时，按 `metric_input_audit` 保存实际输入对象与用途，不用函数名或“语义分数”标签代替核对。候选—参考的内容相近不能冒充候选—新材料的内容保留。先核必要事实和硬约束，记录筛除原因，再比较适用稿；无合格候选时允许不选。未运行、非有限数值、执行失败、输入不适用和真实低分分别记录，既不统一补零，也不补满分。分词或断句不支持当前语言时，即使返回有限的零，也不能当作全文特征缺席。

用模型评分时，还要核提示词实际要求比较谁与谁、判断哪项属性，以及分数方向。填入两个文本，不保证问题确实比较了它们。多提示词汇总保留各自版本、原始分数、有效状态及实际参与项；同一方法的重复调用不计为新增独立读者。普通不评分的改稿无需增加这组记录。

记录生成、选稿与最终评价是否共用指标、表征或评审者。换一个名称不自动成为独立评价；不同表征也不能替代真实读者。选稿规则、候选预算和实际提交都保留，不能把筛选前后多份稿计为独立任务。只交一稿且无自动评分的任务无需填写这些字段。

## 对照办法

同一任务、同一事实材料和同一模型设置下比较三臂：直接写、现有通用写作流程、Text REA V2。参考材料只在允许的路线中加入，并记录其使用范围；否则无法区分 Skill 效果与额外资料的效果。每臂保留生成版和人工修订版。先检查硬约束，再分别盲评遵令、可接受性和偏好。对事实任务，错误和遗漏分开计；对创意任务，收集偏好理由及评审分歧。模型评价可帮助定位问题，结果需要在少量人工案例上校准。

公开人类标注可用于**评价协议校准**：先隐藏标注并锁定本地判断，再揭示并分析具体分歧。记录每条的原文、指令、候选配对与标注者；一位标注者的某条选择不是最终金标准，也不能把几条校准样本算成 V2 生成效果。缺足够领域上下文时允许暂缓可接受性判断，但若仍表达局部偏好，要显式说明它不代表可用稿件选择。

问题片段标签与参考改稿同时存在时，分别核对两种记录，不能假定一一对应。标签未标的位置，参考也可能修改；参考新增的程度、责任或身份可能需要另判。实际参考差异、语义判断和标签一致性分开记，未给共同标注规则时不强行计算片段准确率。只抽到重复类样本，就不声称覆盖转录纠错或其他类型；语料原有的 test 名称也不能证明当前模型从未接触。

实际运行时必须记录每臂能看到的资料、**写前实际读到的方法文件**、模型和会话上下文是否隔离、生成顺序是否随机、首稿后的修订次数，以及匿名评阅是否真的完成。相同事实包不等于相同上下文；事后补读方法不等于写前执行。未隔离的同一助手顺序写稿只能当**探索样本**，不能用三臂胜率证明 Skill 效果。匿名给读者看，也不代表生成过程已受控。

进行顺序复核时，保存展示顺序、选项定义和稿件版本，把原始选项映回稳定候选ID。显式平局、换位后胜者改变、无法判断和解析失败分别保留；汇总若将其中几类折算成平局，保留原状态和折算规则。单次换位分歧先记观察，判断持续的位置偏差还需同序重复等证据；顺序一致也要另核事实与任务要求。普通读稿无需为此重复评审。

要判断多参考的组合方法是否有帮助，给组合流程与对照相同参考、事实和写作要求；参考更多与流程不同不要混在一次归因里。若研究某个维度调整，保留原始输出和调整后的实际输出，记录事实损失及其他属性的变化；多个地方一起改了就不能把读者首选归给其中一个选项。删去某项参考动作的对照可帮助定位贡献，但仍需独立生成、读者结果和足够任务覆盖，不能由静态示例替代。

回顾性材料只用于诊断规则是否抓住已知问题，另列被观察版本的来源、时间关系和混杂因素；不能与前瞻性三臂实验合并计算胜率。结构评价请读者解释一条“需求—参与者—交付”关系，核查关键角色和交接是否说清；不要用标题、表格、品牌或引用数量作替代指标。反馈修订要分别判定“本轮问题解决”和“持续硬约束通过”。

多名编辑或多种候选修订出现时，先比较谁认为**哪里需要改**，再比较对同一位置**怎样改**；把原句保留列为真实选项。用户未点名的额外修改，标编辑假设并等待目标读者或任务结果。这个区分来自 [TETRA](https://aclanthology.org/2024.bea-1.21/) 的编辑位置与类型标签分析，以及 [To Revise or Not to Revise](https://aclanthology.org/2023.acl-long.880/) 对修订史标签噪声的讨论；[相关证据说明](evidence-notes.md)记录适用边界。

若比较的是同一局部原文与修改版，可借鉴 [L01 的五档人工判断](https://aclanthology.org/2025.codi-1.19/)；这是记录选项，不意味着其英语教程句首连接词的比例能迁入中文全文。数据仓库有原始修订 TSV，当前未核到逐条五档人工标签，不能直接当带金标准的测试集。

[Re3](https://aclanthology.org/2024.acl-long.255/)启发反馈—修改—说明三者对齐，但其所谓回应是研究人员整理的摘要，不能误作原作者原话。[Time Is Effort](https://aclanthology.org/2025.hcinlp-1.15/)提醒记录真实人工纠正耗时；其英语句级结果不能变成本地中文长文的预期秒数。两项的本地迁移见[相关证据说明](evidence-notes.md)。

[K05 阅读理解评价](https://aclanthology.org/2024.tacl-1.24/)和 [L04 STARC](https://aclanthology.org/2020.acl-main.507/)启发题目可答性、读者实际答案和题目可猜性分开记录；两篇都不能把少量英语题目的表现直接推广到中文长文。[相关证据说明](evidence-notes.md)回填了 P001 用户对后续两稿的自然度选择，尚无首次阅读理解成绩。

个人口述或图文素材先分“事件事实、画面所见、今天回望、编辑联想”；照片与回忆的关联须单独给来源。报告里公司与产品各自存在，也不证明彼此有具体合作。评价者读完一段后写出自然推得的关系；现稿把来源未确认的关系写成确定联系时，记无支持关系，别直接记成已被证据反驳。

含糊但可能造成多种读法时，先记歧义及风险；没有支持的关系与被证据反驳的关系分别列出。关系判断不只看句子出现顺序，按稿件的时间标记和指代解释。具体步骤见[关系核验](relation-checks.md)。人工构造、公开模型生成和真实用户材料的关系例分组；同一原文的重排与释义归为同一任务家族。自动核验未执行或失败时，不用默认值补出事实或顺序结论。

当 V2 在某类任务里连续出现同一失败时，回查对应机制卡和样本选择。不要用“再生成一次”掩盖系统性错误，也不要无依据地把局部成功推广到所有文类。只有真实对照和复现记录支持的改进才进入 Skill 的稳定规则。

改进可复用方法时另读[迭代与选版](iteration.md)。记录哪些案例已经用于提出规则或挑选候选，按原文家族分配用途；反复用于选版的材料不当未触碰的最终检验。同一稿从 v1 到 v3 达标，只证明这次修订的结果，不是方法版本进步。后续草稿可以比前稿更差，记录退步与回退选择，不用最后一版的身份代替质量判断。
