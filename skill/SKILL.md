# 文字REA

只要求从读者视角审读报告、找理解断点或论证跳步时，读[research-report-critique](../research-report-critique/MODULE.md)，交付有位置、影响与修复建议的发现，未要求时不重写。此分支适用于各类报告；以下成稿主线仅用于写作或改稿。正式学术方法审稿用 research-methods，外部事实真伪另核来源。

把材料组织成符合本次用途的完整文字。先恢复读者、交付范围、现稿及仍有效的要求；常规取舍自行判断，缺口实质影响结果时才提问。内部分析以能帮助成稿为限。

## 一条成稿主线

完整写作按[成文与修订](references/writing.md)贯通以下动作，已有有效内容直接复用：

**读者要理解或经历什么 → 用哪些本次材料支撑 → 参考中的什么动作能帮助组织它 → 安排段落并写成正文 → 脱离材料独立读一遍，再回查并修复具体问题。**

参考提供问题、组织或表达方法，本次材料支持事实；现稿是编辑基线，反馈指向改变范围。提炼出的动作直接用于段落，写后核实际作用。只有用户要求拆解或学习方法时，才把分析本身作为交付。

只改一句、格式或指定段落时，读目标与必要邻文，改后核含义和关联，交付所求范围。只要诊断时止于诊断；明确重构或发现实质错误时处理相应范围。

## 特定文类

- 作品细读、文风研究或原创随笔/故事：[writing-craft](/Users/a1/.codex/skills/writing-craft/SKILL.md)，只借一般写作方法，不复刻在世作者独特文风。
- 作者口述、选定照片、回忆录与旅行照片书：[personal-memory-album](/Users/a1/.codex/skills/personal-memory-album/SKILL.md)，保留作者事实、选图和认可正文；布局修改不自动重写。

## 在主线需要处取用

| 出现的需要 | 接入位置与资源 |
|---|---|
| 学习参考或融合多个范例 | 确定段落时用[迁移指南](references/transfer.md)，动作难以落地时查[具体写法](references/writing-actions.md) |
| 迁移观察、解释或判断方法 | 从参考选动作时用[思维与表达提炼](references/thinking-patterns.md)，再用新材料回答它提出的问题 |
| 匹配本人写法或归纳历史范例 | 选材料时用[文风材料选择](references/style-retrieval.md)；需归纳时读[语料画像](references/corpus-profile.md) |
| 多人物、公司、照片或跨时期叙述 | 核主张与衔接时用[关系核验](references/relation-checks.md)，检查指代、时间、因果与主观归属 |
| 多来源长文或外部研究 | 给主张找依据时用[长文研究](references/research.md)；产业报告沿用 `industry-report-workflow` |
| 规程、操作说明、现场核对卡 | 组织步骤时用[规程写作](references/runbooks.md)，保留条件、权限与失败分支 |

没有相应缺口就继续写；不默认遍历历史、收集全套资料、产生多路候选或等待样段批准。专门领域、文件制作、发送与发布继续使用对应工具和既有授权，正文完成与外部执行分别核实。

## 完成与接续

交付读者能直接使用的完整正文或所求片段，只附影响使用的缺口。修订保留未撤销的旧要求和有效内容；改事实回查关联结论，改顺序回查前提与指代。真实叙事按材料写，创作按获准虚构范围写；本人原文、口述习惯、认可的助手稿和一次偏好保持各自来源。

复杂来源、引用和反馈处理查[协议](references/protocol.md)。仅在比较写作方法时读[评价记录](references/harness.md)与[迭代选版](references/iteration.md)，实际成稿、模型审阅和用户认可分开判断。[依据与边界](references/evidence-notes.md)保留方法来路，来源数量和规则完整不代替成稿效果。
