# 唐三彩载乐骆驼俑

这件唐三彩载乐骆驼俑现藏陕西历史博物馆，1959年出土于西安市西郊中堡村唐墓。整组塑造了一只骆驼和八个人俑，将歌唱与伴奏的场面安排在驼背上。

骆驼昂起颈部，作长嘶状，立在长方形底座上。它的背部另设驮架，托住一块平台，彩色毛毯铺在平台上，八个人俑便安置在这片毯面上。底座承托骆驼，驼背平台承托人物，两层空间上下相接。

七名男子沿平台边缘围坐，盘起双腿，面向外侧演奏。他们都穿汉式衣装，各执不同的胡乐乐器。平台中央站着一名女子，身穿高束腰长裙，头部向上扬起，塑成正在歌唱的形象。外围的七位演奏者与中央的女歌者，共同组成这支驼背上的乐队。

资料：[陕西历史博物馆藏品说明](https://www.sxhm.com/collections/detail/509.html)；[中国国家博物馆文章中的对应藏品图注](https://www.chnmuseum.cn/zx/gbxw/202605/t20260525_279062.shtml)。
