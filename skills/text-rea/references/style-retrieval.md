# 为本次写作选择文风材料

用于按用户本人写法创作或归纳多份范例。已经给了参考就先用所给材料；普通写稿不默认搜索历史。参考身份与使用范围必须可辨。

## 选择适合本次用途的原文

优先匹配文类、受众关系和沟通目的，再看题材、时间及写法差异。用户亲写、口述转录、助手稿、认可的助手稿、转发引用与合作者文字分开；文件由用户拥有或编辑，不证明全文由用户写成。记忆摘要可以帮助找材料或恢复要求，不能充作语言样本。

需要历史时，沿用本次授权和可用访问方式：明确文件或对话先定向读取；使用已连接应用时，按真实工具的作者/发件人、受众、日期等字段检索。应用出现在列表里不代表已连接。读到的结果不足以判断身份或写法时，再读取必要原文；已有适用材料就复用。

只在相关范围内推进。查不到时可调整查询、换另一个相关且获授权的来源、使用用户提供的范例，或在无匹配样本下完成写作并说明影响。不要为凑数量遍历无关应用、磁盘或全部聊天；访问失败不能证明用户从未提供材料，也不授权绕过权限。

选择足以支持当前判断的少量代表篇与必要反例，不设固定三篇门槛。标题和链接可以做定位交接，实际写法分析仍需原文。协作已经获准时，只传任务所需的来源、片段与观察，省略无关私人信息；不默认保存全文、建立长期索引或私人语料库。使用授权不扩成公开发布或模型训练授权。

## 把文风落到动作

先逐篇观察：文章怎样进入主题，段落怎样举证或转折，句子的主体与动词、解释密度、节奏、读者距离，以及怎样结束。保留原文位置、可能作用、适用条件和反例。

题材词、口头停顿、个别口误和一次反馈不直接升格为稳定文风。不同文类允许不同做法；用户喜欢助手的一稿，也不能把它冒充用户亲写。需要更完整画像时按[语料指南](corpus-profile.md)分组，保留不确定性。

将适用做法带入新稿，例如沿用“先给决定、再讲理由”，保留用户有作用的直率、犹豫或重复。范文中的人物、数字、经历、承诺和独特措辞不自动进入新稿；按[迁移指南](transfer.md)核对实际落点。不要靠称呼、口头禅或机械换同义词模拟身份。

成稿首先服务本次事实、受众与要求。若只支持局部写法，就交付局部匹配，不宣称掌握用户全部声音；正文先交付，检索路径和画像只在用户需要或实际影响结果时说明。
