# 从读者问题到段落动作

用于“已经知道要保留什么，但还不知道怎样写出作用”的迁移任务。先看新稿的读者卡在哪里，再选适用动作；不要求凑齐下列卡片，也允许提出更合适的写法。动作落实后直接成文，内部卡片无需交给正文读者。这里的卡片是查找动作的索引；仍要从本次参考取得位置和选择，才可作为本次逆向结论。没有本次原文支撑的动作，只能作为编辑提案。

这些是待检的写作候选：有些来自公开文本的可观察选择，有些是对研究方法的本地改造，有些是编辑提案。出处能解释设计从何而来，不能单独证明读者效果。四个示例由当前助手撰写，不是外部原文、独立比较或用户认可稿。

## 按问题取用

| 读者此处的问题 | 可考虑的动作 |
|---|---|
| 还没找到本文究竟回答什么 | WA01 短答定位 |
| 知道几个名词，却接不上过程 | WA02 追踪对象与变化 |
| 某个结论跳过了他不知道的前提 | WA03 补足缺的一步 |
| 看过两个方案，仍无法取舍 | WA04 同轴比较 |
| 故事不断介绍背景，人物没有推进事件 | WA05 让一次变化落地 |
| 叙述混入人物此刻无从知道的事 | WA06 安排信息的先后 |
| 多份参考都好，却组合成互相打架的稿子 | WA07 按作用分工 |
| 一段已完成任务，末尾仍在换词重复 | WA08 在作用完成处收束 |
| 每句都能读懂，连起来却丢了对象或条件 | WA09 接续对象与条件 |

## WA01 短答定位

- **出处与观察：** NOAA的[海浪](https://oceanservice.noaa.gov/facts/wavesinocean.html)、[上升流](https://oceanservice.noaa.gov/facts/upwelling.html)等短文在问题标题后先给短答或定义。共同网站版式也可能造成这一选择，不能据此认定机构所有文本都应如此。
- **写作动作：** 从新题取一句能直接回答主问题的话；下一段解释读者还不知道的原因或条件。若答案有多条路径，短答保留范围，不用第一条冒充全部。
- **作用假设：** 先给读者一个可定位的答案，再承接解释。若读者原已知道短答，它可能只是重复。
- **不用与失败：** 悬念故事、需逐步论证的争议问题可以延后结论。开头若只有“本文将全面介绍”，读者仍未得到答案；这类目录提示也可能服务长文导航，按载体判断。

## WA02 追踪对象与变化

- **出处与观察：** [上升流正文](https://oceanservice.noaa.gov/facts/upwelling.html)连起表层水移走、下方水补位及后续影响；这种结构也可能由题目本身的物理过程决定。
- **写作动作：** 选一个真实对象，写清它从哪里来、谁对它做了什么、状态或位置怎样改变、改变后的对象交给谁或到哪里。另有独立路径时分段，不强接成先后步骤。
- **作用假设：** 名词被放进同一过程后，读者更容易解释关系；需要实际复述判断，不能只凭动词多就算成功。
- **不用与失败：** 分类、并列观点和纯审美片段未必存在流程。若材料只说两者相关，就不补因果；一条链里主体悄悄变化、去向断裂或另造中间环节，都是需修的位置。

## WA03 补足缺的一步

- **出处与身份：** 这是[协议的解释增量检查](protocol.md#2-复用成稿主线中的结构与动作)的解释增量候选，原始方法线索包括[隐含读者问题研究](https://aclanthology.org/2023.emnlp-main.336/)。P001的局部反馈参与了本地开发，尚无跨文类效果结论。
- **写作动作：** 先写出读者此刻没法接上的一个问题，例如“这个条件为什么会改变结果”；在来源里找回答，把回答放在结论前或紧邻断点处。原理抽象时，可用材料支持的具体对象走一遍。
- **作用假设：** 补的是读者缺的连接，收益也可能来自新增事实本身，而非句式。
- **不用与失败：** 目标读者已掌握前提时可以略过。只把结论换词说一次、答了相邻却不同的问题、比喻带入错误关系，都未完成这一步。

## WA04 同轴比较

- **出处与身份：** 从[迁移指南](transfer.md)的读者任务与编辑合同展开的本地编辑提案；未作为独立实验机制验证。
- **写作动作：** 先确定这次决定的优先条件，再让各方案在同一个条件下回答同一个问题。把“已有事实→对本任务的后果→取舍→何种变化会改变选择”连起来。没有共同证据的维度保留未定。
- **作用假设：** 读者能看出建议怎样从材料产生。结论也可能仅由任务给定的优先条件决定，不能把明确建议归功于某一固定段落顺序。
- **不用与失败：** 纯粹介绍不同对象时不强迫选胜者。给甲列成本、给乙列外观，或把未测维度写成优势，会使比较失去共同依据。

## WA05 让一次变化落地

- **出处与身份：** [DOC §3.2](https://aclanthology.org/2023.acl-long.190/)把故事计划细化到事件、场景和相关人物。将此改成下面的段落动作，是本地编辑提案；没有复现其控制器或把其成绩迁到本稿。
- **写作动作：** 对当前片段确定“开始时怎样、发生什么可见动作、结束时怎样”。重要转折可展开人物遇到的阻力和选择；连接段可概述，不必把所有细节都场景化。
- **作用假设：** 人物行动改变局面，读者才有新的事件可跟随。作用可能来自情节本身，不能只因多了动作描写就称为更生动。
- **不用与失败：** 用户要简介或资料不足时，简述可以更合适。事实叙事只能展开材料支持的行为；虚构叙事按允许的设定创作。动作堆了很多而局面没变，或关键选择直接跳过，需重看本段职责。

## WA06 安排信息的先后

- **出处与身份：** 结合DOC对当前/未来事件的分工与本地[关系核验](relation-checks.md)提出的编辑候选；不是一个已验证的人称或悬念技巧。
- **写作动作：** 采用贴近人物的视角时，让人物先看到、听到或想到某条信息，再据此行动。后续揭示可以改变读者对前文的理解；把计划中作者知道的事与人物此刻知道的事分开。
- **作用假设：** 信息顺序使选择更可理解，或形成有依据的期待。延迟揭示也可能仅增加困惑，需看真实阅读。
- **不用与失败：** 全知叙述、回望叙事和资料说明可以主动越过人物视角；先选本稿的叙述距离。事实私稿不能借悬念补造秘密、当时心理或因果。

## WA07 按作用分工

- **出处与观察：** [Quill固定版](https://github.com/sevenwoood/quill-skill/blob/23b58b48e72675b0b2ad035b7d098653d8f503fd/SKILL.md)将写法分维度融合；本地[迁移指南](transfer.md)把它改为按目标作用组合，没有实测配比。
- **写作动作：** 给参考分配不同工作，例如A帮助组织解释关系，B帮助安排叙事距离。先完成事实和篇章，再在适用位置加入局部语言动作；两份参考争夺同一职责时按新题取舍。
- **作用假设：** 不同长处能够服务同一稿件。若主要收益来自更多参考材料，不能归因于组合步骤本身。
- **不用与失败：** 一个参考已足够时可以只用一个。逐句交替口吻、把两份参考的开头都堆进来，或用无分母的百分比声称已完成融合，都需要改回具体取舍。

## WA08 在作用完成处收束

- **出处与身份：** 来自协议的解释增量候选与P001局部反馈的本地开发；不是“禁止总结”的通用规则。后续自然度选择未分离删句贡献。
- **写作动作：** 对照本段承担的问题，读到足够回答的位置，再决定是否还需要一句承接、限定、提醒或结果。叙事可以停在新局面或动作上；决策文可以结束于建议及改变条件。
- **作用假设：** 少一次无新增作用的重复，读者可能更顺畅；仍需要判断是否丢了必要提醒。
- **不用与失败：** 长文回收线索、教学提醒、法律或操作条件可能需要再说一次。为了短而删掉关键条件，同样没有完成任务。

## WA09 接续对象与条件

- **出处与身份：** [Writing for Readers固定版](https://github.com/Mark-Life/agent-skills/blob/087ec25bee864118b0cccf11b4ad086766c25fc6/skills/communication/writing-for-readers/SKILL.md)建议同一对象保持称呼；[Editorial Line固定版](https://github.com/brycehamrick/editorial-skills/blob/4043b9625b5751f5b8c65de6bf08ce6ce65ae88a/skills/editorial-line/SKILL.md)检查句间承接、代词先行项和无关跳转。下面是本地条件化改造，未独立验证。
- **写作动作：** 确定相邻句分别谈哪个对象，让后一句接住已经出现的对象、结果或问题，再引入下一项动作与条件。同一实体保留稳定称呼；代词有多种指向时写回具体名称。若材料是并列关系，明示比较或分支，不用“因此、随后”补造因果或时间。
- **作用假设：** 读者可沿句子跟住对象及条件，少做一次指代猜测。改善也可能来自重排或内容补全；仅靠出现重复名词或连接词不能证明效果。
- **不用与失败：** 有意换视角、非线性叙事和诗性跳接可以保留；不同概念不能为统一称呼而合并。每句重复全称也会累赘。删句时除信息量，还要看是否失去必要承接；不按固定比例删减，不为“具体”添加无依据的数字或行为。

## 完整示例一：两条来源路径怎样写成解释

**材料与范围：** 只用已核公开材料中的陆地输送、海底热液和移除过程；与P008同源，是开发复用。这里没有新增私人事实，也没有篇幅实验。下文主要采用WA01、WA02。

### 海里的盐从哪里来？

海水中的盐，有很大一部分来自陆地岩石，海底岩石也会提供一些成分。

雨水与岩石接触，带走一部分溶解成分。它们随地表径流进入溪流、河流，最后汇入海洋。

海底还有另一条路径。海水渗入海洋地壳的岩石，受热并溶入部分矿物，再经热液喷口回到海洋。这个过程中，海水与岩石的反应也会移除一部分溶解盐。

这些溶解成分中，有些被海洋生物利用、从水中移除，另一些则长期留存。

[事实依据：USGS](https://www.usgs.gov/water-science-school/science/why-ocean-salty)、[NOAA](https://oceanservice.noaa.gov/facts/whysalty.html)。本示例只解释来源与路径，没有借用上升流的冷水、营养或渔场事实。它不是P008的新版本。

## 完整示例二：同一优先条件下做取舍

**虚构材料：** 团队主要在无网现场工作；甲可离线使用，每月需人工导入；乙可自动同步，需要联网；两者准确性未比较。下面只对这组演示材料提出建议，主要采用WA04、WA08。

### 当前先选甲

团队主要在无网现场查资料，现阶段先选甲。甲能离线使用，覆盖了当前的主要使用条件；乙的自动同步需要联网，在这些现场还发挥不了作用。

选甲后，需要为每月人工导入安排负责人，让材料按期更新。联网条件改善后，可以再比较自动同步带来的收益与人工导入的工作量。两者的准确性还需另做核对。

本稿没有为甲补出更便宜、更准确或已经节省人力等结论。换一组优先条件，建议也可能改变；这不是对真实产品的推荐。

## 完整示例三：用动作把选择写出来

**虚构设定：** 车站末班车将发；主角发现长椅上的红围巾，一个孩子刚随大人走向出口。允许新增动作和对话。下面主要采用WA05、WA06、WA08。

### 红围巾

广播催到第二遍，林桥才看见长椅上的红围巾。刚才坐在这里的小女孩已走到出口，大人一手牵着她，一手拖着箱子。

林桥拎起围巾，朝检票口看了一眼。司机正准备收起踏板。他把脚边的包甩上肩，追向出口。

“等一下！”

大人回过头。小女孩一看见围巾，就松开牵着的手，跑回来接。她把围巾绕到脖子上，仰起脸说了声谢谢。

林桥转身时，车门已经关上。他朝司机挥手，车仍缓缓驶出了站台。他站了一会儿，走回长椅，把包放在刚才搁围巾的地方。

这段用可见动作交代选择与后果，没有把虚构片段写成用户经历。真实稿是否需要补后续安排、改变视角或加入回望，由具体用途决定；本例未获读者评阅。

## 完整示例四：把散落的步骤连起来

**虚构材料：** 上传后系统先检查文件格式；格式不符时提示错误，通过检查才进入转换；转换成功后生成下载链接。未提供处理时长、重试规则或转换失败后的安排。以下主要采用WA09。

**待改稿：** 文件在上传后接受格式检查。通过检查才能转换。系统在格式不符时提示错误。转换成功会生成下载链接。

**修订稿：** 上传后，系统先检查文件格式。检查通过，文件才进入转换；格式不符时，系统提示错误。转换成功后会生成下载链接。

这里把格式检查的两个分支放在一起，再接转换结果；称呼与条件仍来自同一份材料。旧稿已经包含各项信息，修订同时调整了语序、主体表达和句间承接，不能据此分离哪项贡献最大。没有补上处理时长或自动重试，也没有真实读者结果。
