# 从材料到完整正文

普通成稿沿下列关系走一遍；短任务在脑中完成，长文才保留简短记录。各步产生的选择供下一步使用，不分别建多套账或把同一套分析重做数遍。

## 1. 用途决定留下什么材料

从当前请求恢复读者、产物、事实或虚构边界、篇幅、基线和认可范围。想清读者读完应理解、感受或决定什么，再选支撑它的材料。重要对象、具体术语、时间、状态、数字、否定、条件和归属连回来源；源文中相邻的事实也要核它们能否相连。整理口述时分清原话、自我修正、转录疑点和编辑解释。

材料缺口会改变本次结果时才补查；否则保留有用的未知并继续成稿。例子不当完整清单，研究愿望不写成完成事实，主观感受不移给其他人。完整覆盖与重点展开分别决定。

## 2. 让参考动作直接决定段落

没有参考时，按材料比较可成立的主线，选最能完成用途的一条。有参考时，观察它先看什么问题、怎样用证据作判断、怎样推进文字，再用本次材料回答相应问题。只保留本题确实需要的动作；[迁移指南](transfer.md)与[思维提炼](thinking-patterns.md)在此接入。

把选定动作落到段落顺序：这一段要让读者多知道什么，用哪项事实、关系或场景做到，接着自然需要什么。参考的事实、原句、人物身份和过去结论留在原文。多参考按段落作用分工；动作冲突按本次用途取舍。只做短稿时，一条主线和必要段落即可；明确要求逐段批准才等待。

## 3. 沿段落职责写成可独立阅读的正文

把材料顺序变成阅读顺序，前提在需要时出现，主体与条件沿句子接续。个人叙事由材料中的活动和原话承载感受，区分当时念头与现在回望；解释用具体对象走完过程；比较让方案回答共同问题；工作材料按提出、试行、上线与观察结果写明阶段。

写给指定读者的句子应直接完成介绍、解释或叙述。内部对参考、供稿、核验和方法选择的说明，只有本身就是读者任务时才进入正文。来源不明不自动写成作者忘记；当前回望也不替当时补出新的心理。虚构任务按获准设定与空间展开。

需要篇幅下限时，回到已有材料中尚未讲清的细节、关系或评价，选择对读者有用的展开。相邻段落已完成的解释先不重写成结尾；篇幅与真实材料冲突时如实说明，不能靠反复宣布位置清楚、意义重大或增添经历满足长度。Word、PDF等制作沿专门技能处理。

## 4. 先作为读者通读，再回查来源并完成修订

暂时放下事实表，只读正文：读者是否能跟住对象、过程、情绪与判断；哪里突然出现他不知道的参考或整理背景；哪里连续换词回说同一个意思。必要转场、限定与记忆提醒按全文作用判断，不能只因像总结就删除。

再回到材料核疑点及必须保留的内容，尤其是连接句新增的原因、程度、否定或心理。把“问题已在记录里”落实成正文里的修复；改后复读相邻段落，重新核实际篇幅和任务范围。范围/关系正确但生硬的地方，按同一个读者问题重写，避免只补一句解释或审查结论。

正文能独立完成用途、必要内容和格式合格、具体问题已处理时交付；没有实际缺陷就保留已有稿。普通任务无需多路或评分。自查已发现问题却反复保留、真实长稿仍有解释或自然度争议时，改用编辑阶段：把当前完整稿、原材料与有效要求交给本次已获准的独立上下文，直接形成修订正文并说明保留与删改依据；未获准或无此工具时由当前助手单独执行这一步。编辑者从读者用途和来源出发，不以作者自查的“有作用”作为通过依据。最终负责人回查改稿，合并有效修改；编辑意见可以纠正，不按票数或方法标签选稿。只交诊断时交诊断，局部修改保留无关有效内容。

## 按反馈修订

读取当前基线和必要邻文；目标可能被用户改过时，写前重读。内部记清“这次改什么、依据是什么、保留什么、影响哪里”。

| 反馈 | 查现稿中的原因 | 可选动作 |
|---|---|---|
| 太长 | 回答太晚、重复、旁支过多或句子冗长 | 先取舍和重排，再压缩措辞 |
| 太乱 | 中心不清、比较轴混杂、职责重叠 | 归并同轴内容并补连接 |
| 看不懂 | 缺前提、陌生术语、主体含混或过程跳步 | 找第一处断点，补具体对象与中间动作 |
| 太浅 | 只有名称，缺机制、条件或后果 | 用有依据的关系展开 |
| 不像参考 | 迁移维度错了，或新题不适用 | 回到源段作用和新材料重新对应 |
| 不自然、不像我 | 语气不合关系、节奏过齐或总结重复 | 用适合本次的原文校准，保留有效表达 |

这些是诊断起点，不能替用户补出原因。保留原句也是真实选项；局部肯定、整稿认可、继续推进和使用授权分别理解。只改格式时不重写有效正文。

将改动连回反馈，比较实际保留、增加和失去的内容；改事实回查摘要与关联结论，改顺序回查前提、指代和承接。不要只把反馈改写成一句承诺。用户明确拒绝的同一提案不原样重推；新任务或新证据下重新判断，避免形成永久禁词。

当前问题解决、关联内容无实质退步时交付。普通改稿不强制多路生成、评分或反复重写；复杂反馈按[协议](protocol.md#将反馈落实为修改)处理。

## 跨轮接续

长文、多文件或需要交接时，在当前任务工作目录保留最小记录：目标与读者、当前稿和认可范围、仍有效的约束、材料位置与身份、主线与采用的写法、已做和未决、下一步与停止条件、恢复依据。复用已有记录，短任务不额外建档。

记录不产生新授权，也不代表用户接受当前稿。恢复时先读最新要求和当前文件，保留未决矛盾；未经明确要求不把单次偏好写入个人记忆。
