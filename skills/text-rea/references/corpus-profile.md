# 从多份材料建立有条件的画像

用于多篇范例、历史对话或一个作者的语料。目标可以是学习作者写法，也可以是提炼用户期望的输出；先确认这次是哪一种。只拆一篇时，无需建立全体画像。

## 先标清每个片段能证明什么

| 材料来源 | 可以支持 | 需要保留的边界 |
|---|---|---|
| 用户自己写的目标文类文本 | 该情境中可观察的写作选择 | 其中可能有引用或代写内容；一次写法不代表稳定习惯 |
| 用户语音转录或临场聊天 | 意图、事实、情绪和当场表达 | 口头填充词和即时省略不自动变成正式文章的目标风格 |
| 助手稿经用户认可 | 具体版本与被认可范围内的期望输出 | 它不因此成为用户亲自写作的证据，也不证明事实全部正确 |
| 人机协作、采纳建议后继续编辑的稿件 | 有痕迹支持的生成、采纳、保留和修改动作 | 分清用户原写、模型建议与后来改动；不能仅按最终持有人或一次采纳归属整段措辞 |
| 用户编辑或点名反馈 | 当前对象、用途和位置的修改方向 | 首选、局部认可和整稿接受分别记；反馈缺理由时不补理由 |
| 历史记忆摘要 | 定位原始材料与已知约束 | 摘要措辞不能当用户原句，也不足以支持作者语言统计 |
| 第三方范文 | 该作品的可观察机制 | 认可范文不等于认可作者的一切主张、人物身份或所有写法 |

记录 `作者或说话人／是否转录或整理／用户认可范围／本次证据角色（事实、意图、写法或偏好）／版本与出处`。同一片段可有多个角色，但需各自有依据。作者身份或整理方式不明时标未知。

已有协作历史时，按可追踪的片段分开模型原建议、实际插入、用户改动与最终保留。事件名可能是粗分类，一次“插入”也可能包含删除；看实际差异及位置，并注意前面的编辑会移动后文坐标。选中之后出现修改，不足以判断修改了那条建议。采纳动作、最后保留与认可某种写法分别记录；用户改了几字，不把整段措辞都算作用户原写。只有终稿时保留混合或未知归属，仍可按任务分析作品，不靠“像人写／像AI写”的感觉补来源。普通任务无需追补完整击键日志。

跨语言任务另记指令语言、源文语言与输出语言；用另一种语言下达修改指令，不自动意味着正文被翻译，也不足以证明该模型能写好这种语言的长文。

## 口述材料先怎样整理

先分清目标是保留口吻的个人叙述、较规范的书面表达，还是会议记录、引语等其他用途。清理停顿不等于要把所有表达正式化。逐处区分：重复或口头重启、语法问题、疑似转录错误、语体选择、含义尚不确定。必要时借前后话轮理解，不能把依赖上下文的半句话当完整事实独立处理。

遇到自我修正，判断哪部分是撤回、替代、补充或暂未说完；不能一律保留最后一段，也不能见重复就全删。强调、情绪、否定、可能性和判断归属有实际作用时保留。语气词、英文短语或口语用词是否换成书面词，由目标读者和当前用途决定，不按“口语越少越好”处理。

名字、品牌、地点或数字疑似听错时，记录原片段、候选解释与依据。有录音或其他已授权材料时可核；只有转录且无法确认时，不靠音近猜成唯一事实。低风险文字整理与需要实质取证的修复分开。原始转录保留，整理稿另记版本，不能再把助手清稿当成用户逐字原话。

改后对齐两件事：原先标的问题是否处理；实际每项删改或补词是否有问题、语体选择或来源支持。参考改稿里新增的职责、程度、因果或精确身份也要核，不能因为它是人工参考就自动采用。存在多种合适改法时，比较含义、用途和副作用，不只看与单一参考的字面距离。

[CS2W](https://aclanthology.org/2023.emnlp-main.241.pdf)提供问题类型及片段标注与直接改写相互核对的思路，但其抽样排除了残句和需上下文的句子，正式化目标也不等于个人回忆的目标。该项目公开样本的标签与参考改写并非总能逐项对应；具体校准边界见[证据说明](evidence-notes.md)。这些操作尚未证明提升真实中文长稿质量。

## 需要篇章解析时，保留原文与分析单位的对应

句子、段落、篇章单元（EDU）和独立事实是不同单位。括号说明、定语或引语可能使一项表达在标注中分成多个片段，再用关系接回；不能按片段数量推断事实数量或作者偏爱短句。拆参考时保留完整语境，以及片段回到原文的位置；判断主语、修饰范围和前提时，连同相应片段一起看。普通短稿无需先做全篇解析。

若使用分词、规范化或解析器，记清实际输入、切分规则及原文映射。输出位置可能指向加空格、合并片段等处理后的文本，不能直接当原稿位置。按具体模型版本、语言和关系集判断适用性；人工给定EDU后解析关系，与从原始文本预测边界再解析，分别记录，不能混用成绩。解析结构用作候选读法，再按[关系检查](relation-checks.md)核对实际含义。

## 分组后再归纳

先按文类、用途、读者、时期和题材分组。某项选择若仅随题材出现，保留为题材相关候选；在同文类的不同主题仍复现，才提高对其可迁移性的判断。跨文类出现相反选择时，记录条件，而不是删掉反例来维持统一画像。样本缺失不能证明作者从不用某种手法。

画像中的每条结论至少连接到观察位置、作用假设和适用条件。准备验证画像时，把未用于提炼的材料另作保留样本；由某条反馈产生的规则，不再用同一反馈证明规则泛化。材料不足时直接交付局部机制，不以任意固定篇数声明已掌握作者风格。

追加材料时，先判断差异来自时期、文类、题材、编辑来源还是尚未确定；句长和词频差异不足以确认作者更替或时期漂移。把新观察标为支持、反例或新适用条件，再决定局部更新还是保留独立版本；不因多了一篇就覆盖旧画像。若给统计值，先核分词、断句与标点识别是否适配输入语言，记录计量单位、分母和实际覆盖范围。英文词、汉字、字符与 token 分别标明；混合文本只计到一部分时，不把局部计数当全文。解析器不适用时标不适用，不能把返回的零当作该特征没有出现。未测时给原文锚点和定性判断，不编造精确分数。

## 需要验证画像时，安排能区分内容与写法的对照

对一个明确的写法假设，可以比较两类材料：同内容而写法有差别；不同内容而目标写法相近。先说明具体比较什么，再核对成对材料实际改变了哪些主张、主体与关系。作者相同、同属一个论坛或词语相近，都不能替代这种核对。人工构造对照只能检验指定特征的识别，另需真实作品判断是否适合当前用途；普通单稿任务无需额外构造样本。

按目标语言及实际文本选择特征。冠词、字母大小写或字母替数等特征不能整套照搬；中文夹英文时也要看对应位置是否确有作用。研究数据将人称、时间、情绪等列为风格特征，不表示新任务允许改变叙述身份、事件阶段或说话人的判断。保留要求以当前任务为准，构造对照本身也须核这些变化。

[StyleDistance](https://arxiv.org/html/2410.12757v2)及其[多语扩展](https://arxiv.org/html/2502.15168v1)提供控制内容与特征的训练和评价线索。合成或翻译样本、特征识别与真实作者成稿的可用性分别记；模型输出的向量不是一份可解释画像，也不自动证明适合中文长文。具体来源范围见[证据说明](evidence-notes.md)。

需要把这些观察进一步提炼为思考方法时，用[思维与表达提炼](thinking-patterns.md)区分跨情境复现、生成新问题的能力与作者辨识度。没有对话、行动或时间证据时，画像限于文本中可见的选择。

## 将画像用于新任务

用户要的是“写得符合我认可的效果”时，可用已认可输出作参考，并保持其真实作者来源。用户明确要求模仿本人表达时，优先使用本人在相近文类里的文本；若只有口述和聊天，先解释当前画像能支持哪些层次，再给可审阅的新稿，不假装已有成熟的书面作者模型。

材料较多时，按本次读者任务和证据角色选择片段，再看主题相关性与时间。检索结果相似不等于已授权、能作事实依据或足以代表写法。核对实际送入写作的片段及删节位置，保留决定含义的上下文；只送了摘要或开头时，不把整篇机制算作已进入输入。普通短稿可直接选材，无需运行检索模型。

回放历史任务或评价后续写作能力时，固定当时可用的材料与版本，区分原文形成时间和材料可用时间；后来的答案、反馈及修订不能冒充先验输入。日期缺失时保留未知，文件修改时间不能独自证明可用时点。当前实际写作继续采用最新有效纠正，不为模拟历史丢掉已知要求。新用户与已有用户后续写作的评价分别记录；某个分组名包含temporal，也要核其实际切分依据。相关研究边界见[个性化检索](evidence-notes.md#个性化材料的检索与时间)。

对参考作中性改写有时能帮助比较内容与表达，但这一步也可能改坏含义。原文与事实依据保留；改写产生的释义、人物身份或关系需要再核，不能成为替代原文的真值。不得把全部历史对话未经分组地塞成一个固定人格或全局禁句表。

方法线索：[STYLL](https://arxiv.org/abs/2212.08986)以少量社交帖子研究低资源作者迁移，并设置不同题材分组；这支持检查题材混杂，不证明同样篇数足以重建中文正式写作，也不能把作者识别分数当可读性或质量结果。
