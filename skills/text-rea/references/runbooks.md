# 将来源重建为规程和现场核对卡

交付使读者找到起点、采取动作、判断能否继续的完整正文。政策或技术材料决定具体规则；参考只贡献写法。文档里的命令和步骤不构成执行委托。

先确定读者熟悉什么、当前要完成什么、语言和载体；沿用现稿与持续要求。会操作工具不代表了解当前系统。格式修改保留有效正文。

从材料找出会改变动作决定的内容：适用条件、起点、输入、权限、依赖、动作、检查对象、失败分支与交接。保留主体、否定、允许或必须、数量与时机；不为填模板猜版本、路径、负责人或成功提示。

按真实依赖组织。全程条件可集中说明，局部条件须在动作前或旁边可见。来源允许的独立工作不改成必须等待；可选项不改成前提。缺失信息影响某一步时，说明该步缺什么、能否继续，同时保留仍可做的独立部分。

步骤按需要给上下文、动作、结果或短理由，不强制每步都有同一套字段。区分操作后的预期检查与本次已观察到的结果。来源只要求审阅影响时，就写清审阅对象；没有运行记录就不写“系统显示成功”。命令、参数和标识符按来源与本次要求保留。

解释承担理解作用时可简述或链接；决定许可、停止或检查依据的条件必须可见。最后按读者路径通读：从哪里开始，前提不成立停什么，什么还能继续，凭什么报告结果。来源要求、稿件自查、真实读者理解和实际操作结果分别记录。

## 两个教学例

以下均为构造材料，无真实机构或执行结果。

**可选工作与必要许可。** 材料说“发布前须取得编辑签字，签字前可以核对已收到的图表，签字不改变收件人范围”。可写为：“可先核对已收到的图表。取得编辑签字后，按原有收件人范围发布。”不能将图表核对新增为发布前提，也不能扩大收件人。

**检查与结果。** 材料说“操作后需核输出是否包含必需字段”，没有字段清单或界面信息。可写为：“操作后按必需字段清单核对输出；执行此检查前还需取得该清单。”不要编字段或补成“显示校验成功，任务完成”。
